Quick start from source

Package chưa được xác nhận phát hành trên npm theo README của repository. Clone source để build và chạy test:

git clone https://github.com/OCodejs/OCODEJS.git
cd OCODEJS
npm ci
npm run build
npm test

Ví dụ sử dụng các helper:

import { slugify, retry } from "ocode-js";

const slug = slugify("Build a better web");

const result = await retry(
  () => fetch("/api/status"),
  { attempts: 3, delayMs: 200 }
);

Yêu cầu Node.js 18 trở lên. Chỉ gọi browser storage helpers trong môi trường trình duyệt. Không dùng escapeHtml cơ bản thay cho HTML sanitizer chuyên dụng với nội dung HTML không tin cậy.
